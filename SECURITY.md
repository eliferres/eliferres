# Security policy

## Reporting a problem

Use GitHub's private vulnerability reporting on this repository: the Security tab, then "Report a vulnerability". Do not open a public issue for a security problem.

## What to expect

An acknowledgement within two business days. A confirmed problem gets a fix, and the report is credited unless you ask otherwise.

## Scope

This repository holds only the profile page: its README, its images and its link check. A problem in one of the tools belongs in that tool's own repository. A problem in a site or system Ferres Technologies runs goes to the contact in https://ferrestech.com/.well-known/security.txt.
